# Astelume 官网首页

[访问官网](https://astelume.cc.cd/) · [模型广场](https://astelume.cc.cd/pricing) · [使用文档](https://astelume.cc.cd/docs/)

从这里，连接你的下一次灵感。

这里是公开首页的前端源码、图标和原创背景。型号目录从同源匿名接口实时读取，不随仓库发布固定名单。首屏每行仅显示型号与一条公开输入价示例，单位为人民币／百万输入 Token；不按最低价排序。主页没有手动动效按钮，遵循系统“减少动态效果”偏好。

## 首页功能

- 在 Chat、Responses、Claude、Gemini 四种协议间切换，查看请求体与响应示意，复制带环境变量占位符的 cURL。示例不会发送请求或收集密钥；模型是否支持相应协议以文档及模型广场为准。
- 首屏下方按原文静态展示 New API 网关能力：50+ 上游服务适配、100+ 模型计费支持、50+ 兼容 API 路由、10+ 调度控制能力。它们不是本站实时计数，没有跳转或计数动画。
- 「广场品牌与型号」从同源 `GET /astelume/live-model-directory` 读取匿名广场的全部型号及其原始品牌标签。未标注品牌的型号仍展示，但不增加品牌数；型号变体不做猜测合并。整个区块不设搜索、点击、展开或分页。目录失效、断网或读取失败时不沿用旧名单，不影响独立报价或静态能力栏。
- 按「选模型 → 配置客户端 → 发送第一条请求」接入。
- 正式站从模型广场、登录页或控制台点「主页」时，会离开业务应用的内部路由并加载完整官网首页。独立静态托管无需安装 `public/astelume/home-return-v1.js`；它只用于网关页面，不应加到官网自身。

## 本地开发

要求 Node.js ≥ 22.12、npm。

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

把生成的 `dist/` 用于主页静态托管。不要用它替换业务网关、控制台或现有文档目录。本地文档链接转到正式使用文档。该仓库不包含部署主机信息、管理凭据、运营数据、完整模型目录或抓价策略。

## 价格从哪里来

在正式域名，前端请求同源 `GET /astelume/live-group-quotes`，只接收经过服务端过滤、带验证时间和失效时间的公开输入报价。它不是未筛选的原始定价接口；首页不使用原价、历史回填或媒体生成模型。获取失败、过期或断网就撤下价格及动态分组示例。只托管静态文件，或在本仓库运行本地预览时，如未配置可信的同源服务，就不会出现报价；这是预期行为，不会使用演示数字。
