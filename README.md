## 本地开发

要求 Node.js ≥ 22.12、npm。

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

把生成的 `dist/` 用于主页静态托管。不要用它替换业务网关、控制台或现有文档目录。本地文档链接转到正式使用文档。该仓库不包含部署主机信息、管理凭据、运营数据、完整模型目录或抓价策略。

## 价格从哪里来

在正式域名，前端请求同源 `GET /astelume/live-group-quotes`，只接收经过服务端过滤、带验证时间和失效时间的公开输入报价。它不是未筛选的原始定价接口；首页不使用原价、历史回填或媒体生成模型。获取失败、过期或断网就撤下价格及动态分组示例。只托管静态文件，或在本仓库运行本地预览时，如未配置可信的同源服务，就不会出现报价；这是预期行为，不会使用演示数字。

品牌仅用于识别模型家族，不代表厂商合作或背书。官方图标归各自权利人所有，来源见 [品牌标识说明](./BRANDS.md)。
